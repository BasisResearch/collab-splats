Pane 1 — Frame Selection Metrics

How should we display per-frame metrics alongside the frame strip?

A

Stacked time-series panel

4 small charts stacked vertically (flow / rotation / translation / histogram similarity), all sharing the same x-axis (frame index). Selected frames shown as vertical green bands across all charts. Scrubbing the frame slider highlights position across all plots.

▲ green lines = selected frames
B

Single composite score

Compute a single "frame quality" score combining all 4 metrics (configurable weights). Show one sparkline. Selected frames shown as green dots on the line. Simpler but loses per-metric breakdown.

FRAME QUALITY SCORE
● green = selected frames
C

Tabbed metric charts

Same 4 time-series as A, but shown one at a time in a small tab switcher above the frame strip. Less vertical space, but only one metric visible at once.
