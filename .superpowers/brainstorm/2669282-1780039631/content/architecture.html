Data flow

fetch() REST calls · EventSource for SSE streams

serves static files + REST + SSE

frame_sampling · VGGTXCreator · MeshPipeline · etc.

💾 /workspace/outputs/
zarr · PLY · JPEGs · run_config.yaml ← served as static files

Key patterns

LONG OPS → SSE
Frame extraction, reconstruction, semantics → EventSource streams logs + progress to browser in real time. No polling.
MEDIA → STATIC FILES
Frames, video, PLY served directly as files. Browser caches. No base64. No Bokeh websocket. Instant.
3D → THREE.JS
PLY pointcloud + mesh via Three.js PLYLoader (same as viewer you liked). GPU-accelerated, fluid.
Branch strategy

feat/webapp off refactor/cu121. Panel dashboard stays on existing branches untouched. New entry point: python -m collab_splats.webapp on port 7860 (same port, different runner). Can run both simultaneously on different ports during transition.
