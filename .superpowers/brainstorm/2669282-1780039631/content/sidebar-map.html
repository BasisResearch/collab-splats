Implementation note

Sidebar sections are HTML components rendered/hidden via JS on tab switch — no page reload. Session section is always mounted. Pointcloud, Semantic, View/Mesh, Localize sections mount only when their tabs are active. Shared state (selected creator, conf, extractor) lives in a small JS state object synced with FastAPI on change.
