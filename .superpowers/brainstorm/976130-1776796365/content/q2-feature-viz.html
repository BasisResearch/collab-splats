How should patch features be visualized?

After extracting a (C, pH, pW) feature tensor — what should the notebook display?

A

PCA → RGB overlay

Reduce feature channels to 3 via PCA, map to RGB, blend over original frame. What the dashboard does — shows semantic regions as color clusters.

original image + colored patch grid blended on top
B

PCA → RGB + similarity heatmap

PCA visualization first, then a text-query heatmap (for extractors that support it). Two outputs per extractor.

PCA image | heatmap for "bird" vs "background"
C

Raw feature channels

Display first N individual feature channels as grayscale images. Shows raw learned representations, less interpretable but more transparent.
