Notebook structure — how to organize extractor sections?

Both notebooks need to show multiple models. How should cells be arranged?

A

Linear narrative

Flat cells, top to bottom. Load extractor → extract → visualize → query. Repeat for next extractor. Easy to read, some repetition.

## 1. Setup
## 2. MaskCLIP
  load → extract → PCA → heatmap → masked
## 3. Talk2DINO
  load → extract → PCA → heatmap → masked
B

Helper functions defined once, called per extractor

Define visualize_features(extractor, image, queries) early. Each extractor section is just: load → call helper → display. DRY, but less transparent for new readers.

## Helpers
  def visualize_features(...)
## MaskCLIP
  extractor = ...; visualize_features(...)
## Talk2DINO
  extractor = ...; visualize_features(...)
C

Identical cell blocks per extractor

Each extractor gets the same 4-cell template (markdown header + 3 code cells). Easy to diff between extractors, easy to copy a block and swap in a new model.

## MaskCLIP
  [cell] load
  [cell] extract + PCA
  [cell] heatmap + masked
## Talk2DINO
  [same 3 cells]
