Mesh#

TSDF meshing from posed depth + RGB, then cleaning, decimation and texturing. Every entry point takes plain arrays, never a PointcloudResult: only the caller knows which resolution grid it is on. collab_splats.mesh exports compute_tsdf_voxel_size, create_tsdf_mesh, clean_repair_mesh, prepare_mesh and create_texture_mesh. The pipeline runs it as the mesh stage (mesh: in the yaml, --stages mesh; keys in Reconstruction Pipeline Configs); the 04_mesh tutorial walks through fusion, cleaning and texturing.

Fusion#

import open3d as o3d

from collab_splats.mesh import (
    clean_repair_mesh,
    compute_tsdf_voxel_size,
    create_tsdf_mesh,
    prepare_mesh,
)

voxel_size = compute_tsdf_voxel_size(depths, c2w, K, depth_fx=model_fx)
mesh = create_tsdf_mesh(
    depths,  # (N, H, W) float32, 0 = no observation
    rgbs,  # (N, H, W, 3) uint8
    c2w,  # (N, 4, 4) camera-to-world
    K,  # (N, 3, 3) pixel-center, at the depth resolution
    voxel_size=voxel_size,
)
cleaned, real = clean_repair_mesh(mesh, c2w)  # real: floater-cut surface, no hull or fill
prepared = prepare_mesh(cleaned, voxel_size=voxel_size, max_faces=1_500_000)
o3d.io.write_triangle_mesh("scene/mesh.ply", prepared)

  • No file IO in collab_splats.mesh except the texture writer. The stage deletes a stale mesh.ply before fusing and writes it last, after texturing: mesh.ply is the done marker, so a run that fails partway leaves none and is re-run, never skipped.

  • The voxel is derived, never set. The world has no fixed scale (feedforward depth is roughly unit scale, a COLMAP-scale reconstruction one to two orders of magnitude larger), so an absolute voxel or depth cutoff tuned on one scene empties or explodes the next.

  • compute_tsdf_voxel_size: depth_px (mesh.voxel_depth_px, 4) depth-pixel footprints, depth / depth_fx, at the ref_percentile depth (mesh.voxel_ref_percentile, 50). depth_fx is the focal of the grid the depth was predicted on: the model grid for feedforward, since depth upsampled to the frame grid carries no finer detail. It then counts the 16³ surface blocks the voxel would allocate and coarsens by the square root of the overshoot until they fit max_gb (8).

  • Depth cutoff: before sizing the voxel, the stage zeroes depth beyond the mesh.depth_trunc_percentile (99, in (0, 99]) percentile of positive depth; a far tail crashes Open3D.

  • sdf_trunc defaults to 4 × voxel_size; the stage passes mesh.sdf_trunc_mult × voxel_size (6.0). A band narrower than one voxel raises.

  • create_tsdf_mesh runs on CUDA when Open3D has it, else on the CPU, and raises rather than fusing quietly wrong (validate_views): non-uint8 RGB, view-count or resolution mismatches, and a principal point outside the depth grid. Pairing one grid’s depth with the other grid’s K otherwise collapses the mesh instead of failing. An out-of-scale depth_trunc is not checked: Open3D treats it as a legitimately empty volume.

Composing the inputs#

mesh.source picks the depth: feedforward (default) or splats.

Feedforward, at frame resolution. frame_depths (collab_splats.pointcloud.utils) confidence-masks the model-grid depth and guided-upsamples it onto the frames, so the full-res result.intrinsics is the K to fuse with:

from collab_splats.geometry.transforms import invert_poses
from collab_splats.pointcloud.utils import frame_depths
from collab_splats.preproc import frame_idx_from_path, read_frames

image_ids = [frame_idx_from_path(p) for p in result.image_paths]
rgbs = read_frames(images_dir, image_ids)
depths = frame_depths(result, rgbs, conf_percentile=20, exclude=sky)
c2w = invert_poses(result.extrinsics)
K = result.intrinsics  # full-res; depth_fx from result.model_intrinsics

  • result is the PointcloudResult from pointcloud.zarr. It stores K twice: intrinsics on the frame grid and model_intrinsics on the model grid. Mixing one grid’s depth with the other grid’s K is the collapse above.

  • conf_percentile is mesh.conf_percentile (20; null = off). A reconstruction with no confidence array (sfm) fuses unmasked and logs it.

  • sky is the sky_masks stack when mesh.mask_sky is on, else None. Passed as exclude=, the percentile ranks only non-sky pixels, so one setting cuts the same share of real surface whether a video is a quarter sky or none.

  • With mesh.mask_sky the stage passes the sky masks as exclude=: the percentile ranks only non-sky pixels, so the same setting cuts the same share of real surface on every video.

  • At model resolution (notebooks, evals): result.depth, result.images transposed to (N, H, W, 3) and scaled to uint8, invert_poses(result.extrinsics) and result.model_intrinsics. No lift.

From a trained splat. render_tsdf_inputs (collab_splats.splats.checkpoint) renders every training camera from the splats stage’s ckpt.pt, at frame resolution, with the poses they were rendered from, pose-opt deltas included. Nothing to lift or re-pose. The stage never auto-runs the splats stage; a missing checkpoint raises.

from collab_splats.splats.checkpoint import render_tsdf_inputs

depths, rgbs, c2w, K, image_ids = render_tsdf_inputs(backend_dir / "splats" / "ckpt.pt", images_dir)

  • image_ids: the source frame index of each row, in the checkpoint’s render order (not filename order), the same values read_frames takes; per-view artifacts (sky masks, per-frame scores) line up through it.

  • K comes back pixel-center; depth is zeroed where alpha is 0.

  • depth_source picks the 2dgs depth: "expected" (default, used by the stage) is the alpha-weighted depth, defined wherever anything contributes but smeared across depth discontinuities; "median" is median_depth, sharper but blank wherever no gaussian crosses the median, which opens holes on grazing ground. A 3dgs checkpoint has only depth.

  • images_dir swaps the rendered RGB for the source keyframes matched by image id, as the stage does; omit it to fuse the render’s own color.

Masking sky. Sky has no surface, but every depth source assigns it one, so it fuses as a backdrop and seeds floaters. mesh.mask_sky (true) zeroes depth wherever the sky segmenter fires, before fusion, on both sources:

from collab_splats.semantics.segmentation import sky_masks

masks = sky_masks(images_dir, idxs=image_ids, cache_dir=scene_dir / "sky")  # (N, H, W) bool
depths[masks] = 0.0

  • idxs takes source frame indices in the order wanted; the stage passes each source’s image_ids. Sky probabilities cache as PNGs under <scene>/sky/, so a re-run pays for inference once.

  • Backend: skywater, a SegFormer MiT-B2 registered as BaseSegmentation.get("skywater").

  • Masking applies to mesh depth only, never to the splats stage’s depth targets, which do take mesh.conf_percentile: the asymmetry is deliberate.

Depth + RGB views fused into a mesh.

  • create_tsdf_mesh: the entry point, Open3D VoxelBlockGrid (CUDA when available) then extract

  • compute_tsdf_voxel_size: voxel edge from the depth’s own pixel footprint, coarsened to a memory budget

  • no file IO: the caller writes the mesh once it is final

collab_splats.mesh.tsdf.compute_tsdf_voxel_size(depths: ndarray, c2w: ndarray, K: ndarray, *, depth_fx: float, depth_px: float = 4.0, ref_percentile: float = 50.0, max_gb: float = 8.0, stride: int = 8) → float[source]#

TSDF voxel edge from the depth’s own resolution, coarsened until the grid fits a memory budget.

  • one depth pixel spans depth / depth_fx world units; the voxel is depth_px of them at the ref_percentile depth

  • so the voxel follows the scene’s scale and the depth resolution, with no world-unit constant

  • if the surface’s 16³ voxel blocks would exceed max_gb, the voxel is coarsened until they fit

  • block count scales with 1 / voxel², so each step coarsens by the square root of the overshoot

Parameters:

  • depths – (N, H, W) depth in world units, 0 = no observation.

  • c2w – (N, 4, 4) camera-to-world poses.

  • K – (N, 3, 3) intrinsics at the depths’ resolution.

  • depth_fx – focal length in pixels of the grid the depth was predicted on.

  • depth_px – voxel edge in depth-pixel footprints.

  • ref_percentile – depth percentile the footprint is taken at; lower favors near surfaces.

  • max_gb – memory budget for the voxel blocks the surface occupies.

  • stride – pixel subsample per axis for the depth statistics and the block count.

Returns:

Voxel edge in world units.

Raises:

ValueError – depths holds no positive depth.

collab_splats.mesh.tsdf.create_tsdf_mesh(depths: ndarray, rgbs: ndarray, c2w: ndarray, K: ndarray, *, voxel_size: float, depth_trunc: float | None = None, sdf_trunc: float | None = None, max_blocks: int = 30000) → open3d.geometry.TriangleMesh[source]#

Integrate depth + RGB views into a VoxelBlockGrid and extract its mesh.

  • runs on CUDA:0 when Open3D has CUDA, else on the CPU; same grid, same mesh

  • the block hashmap starts at 10k blocks and grows on its own

  • Open3D floors projected u, v (pixel-corner), so K shifts +0.5 once here

  • scenes past max_blocks fuse in spatial tiles; the welded mesh equals the single grid’s

Parameters:

  • depths – (N, H, W) depth in world units, 0 = no observation.

  • rgbs – (N, H, W, 3) uint8 RGB at the same resolution as depths.

  • c2w – (N, 4, 4) camera-to-world poses.

  • K – (N, 3, 3) pixel-center intrinsics at the depth resolution.

  • voxel_size – TSDF voxel edge in world units.

  • depth_trunc – depth beyond this (world units) is ignored; None keeps every depth.

  • sdf_trunc – truncation band in world units; None = 4 × voxel_size.

  • max_blocks – blocks per grid, halo included; Open3D extraction faults past 32,768.

Returns:

The extracted mesh with per-vertex color.

Raises:

ValueError – sdf_trunc is narrower than voxel_size.

Cleaning#

clean_repair_mesh(mesh, c2w=None, ..., use_convex_hull=False) returns (cleaned, real): remove_floaters (in place), optionally make_convex_hull, then fill_holes. real is the mesh right after the floater cut, the texture occluder. Cleaning is not optional in the pipeline; remove_floaters, make_convex_hull, fill_holes, trim_mesh_edges and bridge_mesh_edges are public for callers who want one step alone.

Every threshold is relative to the mesh’s own extent, never a world distance, so one default works on a metric scan and on a scale-free feedforward reconstruction alike. get_scene_scale is that extent: the diagonal of the 1st-99th-percentile bounding box, which ignores a stray far component.

  • min_area_frac (6e-6): components with area under this × scene_scale² go; scale is taken from the largest component alone.

  • max_gap_frac (0.01): components whose centroid is further than this × scene_scale from the main body go, however large.

  • max_hole_perimeter_ratio (0.014): holes with a perimeter under this × scene_scale are filled; anything bigger is a real opening (a doorway, the missing back of the scene).

  • subdivide_fill (True): patches are triangulated, then one meshlib subdivideMesh over all patches (to the mesh’s edge length) and one cotan positionVertsSmoothly of their new vertices, so a patch does not read as a flat fan. False leaves a flat lid.

  • max_plain_edges (8, fill_holes only): loops with at most this many edges take a plain flat lid; 0 subdivides every patch.

  • A component’s outer rim is never filled, whatever the bound: its widest loop, when that loop spans at least half the component’s bounding box. A sheet’s rim spans all of it; a hole in a closed surface spans a fraction, so a sphere with one hole still gets it filled.

Convex hull (mesh.use_convex_hull, true in configs/base.yaml; set false indoors and for objects). make_convex_hull(mesh, c2w) finds the ground plane from the camera path and right vectors, cuts and trims the ragged outer edge, then patches the ground out to a rounded convex hull. When no RANSAC plane faces the camera up, the largest plane is the ground and a warning is logged; steps are in its docstring below.

Preparing mesh.ply#

The stage always ships the prepared mesh, textured or not. prepare_mesh(mesh, *, voxel_size, ...) returns a new mesh and leaves its input unmodified:

  1. fill_holes at full density with max_hole_perimeter_ratio (3.9): outer rims stay open by rule, so the bound only stops the largest interior openings. With the convex hull on, more inlets are interior holes by now.

  2. decimate_mesh: meshlib QEM to an error bound in voxels (decimate_max_error, 0.5 × voxel_size), so the budget follows the fusion resolution, not a triangle count; past max_faces (mesh.max_faces, 1500000) a second pass decimates on to that count whatever error it costs, so texturing cost stays bounded.

  3. make_manifold: split non-manifold vertices, drop degenerate, duplicate and fold-over faces.

  4. fill_holes again with subdivide_fill=False, then make_manifold: flat lids over the pinholes decimation and repair open, then a repair of what the lids fold.

  5. smooth_iterations > 0 only (mesh.smooth_iterations, 30; function default 0): meshlib relaxKeepVolume, then make_manifold. Last, so decimation never sees it; vertices move, faces stay.

Filling only after decimation leaves fold-over faces.

Mesh cleanup at full density, then preparation for UV unwrapping.

  • clean_repair_mesh: remove_floaters, optional make_convex_hull, fill_holes

  • remove_floaters: drop components that are small or far from the main body

  • fill_holes: patch interior loops under a perimeter bound; the outer rim stays open

  • make_convex_hull: trim_mesh_edges, patch the ground out to a rounded hull, bridge_mesh_edges

  • prepare_mesh: fill_holes, decimate_mesh (error-bounded QEM), make_manifold into a clean manifold mesh

  • thresholds are scene-relative: fractions of get_scene_scale, or cells of the median edge

Trim the ragged outer edge, then patch the ground out to a rounded convex hull.

  • lengths are in cells: pixels of the top-down image of the mesh, one median edge length each

  • ground: first of 3 RANSAC planes facing the camera up, else the largest; up on the cameras’ side

  • cut: faces outside the rounded hull, then trim_mesh_edges on the ragged outline

  • patch: uncovered hull cells get a sheet pinned to the rim, pulled to the eroded ground

  • outline_open – see trim_mesh_edges.

  • rim_max_dz – join a rim vertex only within this of its neighbors’ median height, cells.

  • rim_max_edge – drop patch triangles touching the rim with a 3D edge over this, cells.

  • bridge_radius – see bridge_mesh_edges (radius).

  • min_piece_faces – pieces with fewer faces are dropped.

  • min_up_cos – smallest |plane normal . expected up| that counts as ground; below it on every plane, the largest plane is used.

Texturing#

create_texture_mesh(mesh, occluder, out_dir, rgbs, c2w, K, *, voxel_size) bakes the views into one albedo atlas (mesh.texture, true; CUDA only, the stage refuses before fusion without it). mesh is the prepared mesh, unwrapped as is; occluder is the real mesh clean_repair_mesh returns, so hole-fill patches never hide a real surface. The stage writes to <backend>/texture/.

  1. unwrap_view_charts: the source images are the charts. Each face takes the view in which it owns at least 75% (frac) of its projected pixels in that view’s nvdiffrast face-id buffer, smoothed toward its neighbors’ views; its UVs are its pixel coordinates there. The z-buffer gives each pixel to one face, so faces in one camera chart cannot overlap. Unseen faces get one flat patch per connected group. Charts are tiled and packed; flipped or overwritten faces regroup into flat patches and are repacked.

  2. project_images_to_texture: nvdiffrast rasterizes the atlas into per-texel world position and normal. Occlusion is a per-view nvdiffrast depth render of the occluder: a texel is hidden when its nearest raster pixel holds a surface nearer by more than a voxel. Bilinear samples (grid_sample) are weighted by pixel size at the texel. Each image splits into a Gaussian-blurred base (blur_pix_sigma=16 source pixels) and its detail; detail comes only from views that resolve the texel nearly as finely as its best (view_ratio=1.5), the base averages every view that sees it, so per-frame exposure does not step where the sharp views change. fill_missing_pixels (push-pull) fills every texel no view reached.

  3. _dilate_chart_gutters: chart edge texels grow into their own padding, so bilinear lookups never pull in a neighboring chart.

  4. write_textured_obj (collab_splats.utils.io): mesh.obj + mesh.mtl + albedo.png. Each position and smooth normal is written once and faces index v/vt/vn separately, at 6 decimals. UV seams add vt entries, never positions: the OBJ’s v lines are the prepared mesh’s vertices. White diffuse (Kd 1 1 1): a grey Kd darkens the texture in every viewer.

Texture a fused mesh: one albedo atlas baked from the source views.

  • input: prepare_mesh output (clean.py)

  • unwrap_view_charts: UV atlas from camera-projection charts (nvdiffrast face ids)

  • project_images_to_texture: per-view depth test; detail from the sharpest views, blurred base from all, then fill

  • _dilate_chart_gutters: chart edges copied into their own padding

  • write_textured_obj (utils/io.py): mesh.obj + mesh.mtl + albedo.png

collab_splats.mesh.texture.project_images_to_texture(verts: ndarray, faces: ndarray, normals: ndarray, uvs: ndarray, rgbs: ndarray, c2w: ndarray, K: ndarray, tex_size: int, occlusion_eps: float, occluder: tuple[ndarray, ndarray] | None = None, view_ratio: float = 1.5, blur_pix_sigma: float = 16.0) → ndarray[source]#

Visibility-weighted projection of images into a mesh’s UV atlas.

  • texels no view reaches take a push-pull fill from their seen surroundings

  • a hole-filled mesh hides its own observed surface, so pass the pre-fill mesh as occluder

  • view_ratio 1.0 is single-best-view (sharpest, seam-prone); large values average everything

  • each image splits into a blurred base (blur_pix_sigma) and the detail left over

  • base color averages every view that sees the texel, so color does not jump where the sharpest view changes

  • detail comes only from the view_ratio views, so the texture stays sharp

Parameters:

  • verts – (P, 3) vertex positions.

  • faces – (F, 3) vertex indices.

  • normals – (P, 3) vertex normals; texels facing away from a view take nothing from it.

  • uvs – (F, 3, 2) per-corner UVs in [0, 1], v up (from unwrap_view_charts).

  • rgbs – (N, H, W, 3) uint8 images.

  • c2w – (N, 4, 4) camera-to-world poses.

  • K – (N, 3, 3) intrinsics at image resolution.

  • tex_size – atlas edge in texels.

  • occlusion_eps – depth-test tolerance in world units (≈ voxel size); stops self-occlusion.

  • occluder – (verts, faces) to depth-test against instead of the mesh.

  • view_ratio – keep views whose pixel size at the texel is within this factor of the texel’s best.

  • blur_pix_sigma – base band Gaussian sigma in source pixels; 0 takes the whole image from the view_ratio views.

Returns:

(tex_size, tex_size, 3) uint8 albedo.

collab_splats.mesh.texture.unwrap_view_charts(mesh: open3d.geometry.TriangleMesh, c2w: ndarray, K: ndarray, image_hw: tuple[int, int], tex_size: int, *, frac: float = 0.75, small_px: float = 4.0, rel_tol: float = 0.01, alpha: float = 0.25, rounds: int = 40, tile_m: float = 0.5, pad: int = 1, min_owned: float = 0.5) → tuple[ndarray, ndarray][source]#

UV atlas whose charts are the source images themselves.

  • a face may take a view only if it owns its pixels in that view’s face-id buffer

  • the z-buffer gives each pixel to one face, so faces in one camera chart cannot overlap

  • faces no view fully sees get one flat patch per connected group, along its mean normal

  • flipped or overwritten faces regroup into flat patches the same way; any still broken become single charts

Parameters:

  • mesh – prepare_mesh output.

  • c2w – (V, 4, 4) camera-to-world poses.

  • K – (V, 3, 3) intrinsics at image resolution.

  • image_hw – (height, width) of the views.

  • tex_size – atlas edge in texels.

  • frac – share of its projected area a face must own for the view to count.

  • small_px – faces under this projected area use a centroid depth test instead.

  • rel_tol – relative depth tolerance of that centroid test.

  • alpha – smoothing lets a face switch to a neighbor’s view scoring >= alpha of its best.

  • rounds – smoothing rounds.

  • tile_m – charts are cut into tiles of this world size, so no box spans the atlas.

  • pad – gutter texels around each chart box.

  • min_owned – a face owning under this share of its expected texels is overwritten.

Returns:

(F, 3, 2) float32 UVs in [0, 1] with v up, and (C, 4) chart boxes x, y, w, h in texels.

Vertex features#

The semantics stage (after mesh) lifts features straight onto the vertices with collab_splats.semantics.lifting.lift_features, passing a result whose points are the vertices and no pixel_indices: each vertex projects into every frame and averages the depth-consistent samples; a vertex no frame sees stays zero (unobserved). They are stored as vertex_features in <scene>/<backend>/semantics/<extractor>_lifted.zarr, which python -m collab_splats.viewer local <scene>/<backend> shows on the mesh.

  • collab_splats.semantics.lifting.transfer_features(targets, points, features, k=5, max_dist=0.03): Gaussian-weighted k-NN scatter of point features onto targets; pass the points themselves to smooth.

  • collab_splats.semantics.utils.cluster_points, given the vertex positions, groups high-scoring vertices into spatially connected clusters.

Utilities#

to_meshlib / from_meshlib convert to and from meshlib; face_edge_ids, adjacent_face_pairs, face_components and face_areas give face connectivity; validate_views is the view-array contract shared by create_tsdf_mesh and create_texture_mesh.

Mesh helpers shared across tsdf, clean and texture.

  • to_meshlib / from_meshlib: Open3D <-> meshlib conversion

  • face_edge_ids / adjacent_face_pairs / face_components / face_areas: per-face geometry and connectivity

  • validate_views: the view-array contract for fusion and texturing

collab_splats.mesh.utils.face_edge_ids(faces: ndarray, n_verts: int, *, directed: bool) → ndarray[source]#

An id for each of a face’s 3 edges, (F, 3); two faces sharing an edge get the same id.

  • id of edge a->b: a * n_verts + b, so id // n_verts and id % n_verts give its ends back

  • directed on: a->b and b->a get different ids (winding matters)

  • directed off: a->b and b->a share one id, the smaller end first

Parameters:

  • faces – (F, 3) vertex indices.

  • n_verts – vertex count, the id radix.

  • directed – keep edge direction in the id.

Returns:

(F, 3) int64 edge ids.
