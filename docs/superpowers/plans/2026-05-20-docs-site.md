# Documentation Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a public Sphinx documentation site (GitHub Pages) with a tutorials section (13 pre-executed Jupyter notebooks) and an API reference (autodoc from docstrings).

**Architecture:** Sphinx source lives in `docs/source/`. Notebooks stay in their existing locations (`docs/splats/`, `docs/semantics/`, etc.) and are symlinked into `docs/source/tutorials/` — reorganizing is just moving symlinks. API reference uses `automodule` with `autodoc_mock_imports` so CI never needs CUDA/nerfstudio installed. GitHub Actions builds on every push/PR and deploys to `gh-pages` branch on merge to `main`.

**Tech Stack:** Sphinx, pydata-sphinx-theme, nbsphinx (`execute=never`), myst-parser, sphinx.ext.autodoc+napoleon, GitHub Actions + peaceiris/actions-gh-pages

## Installation

collab-splats requires Python 3.10 and CUDA. Use the provided setup script:

```bash
git clone https://github.com/BasisResearch/collab-splats
cd collab-splats
bash setup.sh
```

### Docker

A pre-built Docker image is available:

```bash
docker pull tommybotch/collab-splats:latest
```

## Quickstart

### Gaussian Splatting with depth and normals

```python
from collab_splats.wrapper.splatter import Splatter, SplatterConfig

config = SplatterConfig(
    file_path="path/to/video.mp4",
    method="rade-gs",
    output_path="path/to/output",
)
splatter = Splatter(config)
splatter.preprocess()
splatter.train()
```

### Semantic feature splatting

```python
config = SplatterConfig(
    file_path="path/to/video.mp4",
    method="rade-features",
)
splatter = Splatter(config)
splatter.preprocess()
splatter.train()
```

See the [Tutorials](tutorials/index) for full worked examples.
```

## Task 8: Add GitHub Actions workflow

**Files:**
- Create: `.github/workflows/docs.yml`

- [ ] **Step 1: Write the workflow file**

Create `.github/workflows/docs.yml`:

```yaml
name: docs

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

permissions:
  contents: write

jobs:
  docs:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - name: Set up Python 3.10
        uses: actions/setup-python@v5
        with:
          python-version: "3.10"

      - name: Install docs dependencies
        run: |
          pip install --upgrade pip
          pip install sphinx pydata-sphinx-theme myst-parser nbsphinx sphinxcontrib-bibtex

      - name: Build docs
        run: sphinx-build -b html docs/source docs/_build/html -W --keep-going

      - name: Deploy to GitHub Pages
        if: github.ref == 'refs/heads/main' && github.event_name == 'push'
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: docs/_build/html
```

Note: CI installs only the doc tools (not the full package with CUDA deps). The `autodoc_mock_imports` in `conf.py` handles all heavy imports so autodoc works without the real packages installed.
