## Coupling rules (enforced by review)

| File | Allowed imports | Forbidden |
|------|-----------------|-----------|
| `submap.py` | numpy, dataclasses, typing | gtsam, torch, DINO |
| `retrieval.py` | numpy, torch (lazy), DINO-SALAD model loader, typing | gtsam |
| `alignment.py` | numpy only (numba optional) | gtsam, torch, DINO |
| `pose_graph.py` | gtsam, numpy, our submap | torch, DINO |
| `closure.py` | imports above | none additional |
| `__init__.py` | all above for re-export | none |

Any violation → fix before merge.
