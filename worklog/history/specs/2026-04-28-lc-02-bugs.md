## Goal

Fix all silent bugs that do NOT require pose-graph topology changes. After this spec:
- Output shape is `(N,4,4)` matching input frame count (F3)
- No backend silently accepts every retrieval candidate (F5)
- Pose convention asserted at runtime (F7)
- Retrieval threshold semantically meaningful (F8)
- Loop candidates spatially deduped (F9)
- More candidates surfaced per submap (F10)

Pose-graph math (F1, F2, F4, F11) NOT touched here. Saved for spec 3.

## Tasks

### F3 — Overlap-region dedup at output

**File:** `collab_splats/pointcloud/feedforward.py:_loop_close` (around line 261).

**Change:** before `np.concatenate`, build a global-frame-index → submap-index mapping. For frames present in multiple submaps (overlap region), prefer the **earlier** submap's pose (canonical-owner rule). After concatenation, slice/index to recover `(N, 4, 4)`.

**Helper:** add `dedup_overlap(submap_results: list[np.ndarray], submap_starts: list[int], total_frames: int) -> np.ndarray` to `loop_closure/alignment.py` (the module exists empty from spec 1 — populate this function only).

**Acceptance:** for `N=100, K=20, O=4` → output shape `(100, 4, 4)`. For `N=21, K=20, O=4` → output shape `(21, 4, 4)`.

### F5 — Default verifier raises

**File:** `collab_splats/pointcloud/feedforward.py:137-139`.

**Change:**
```python
def _verify_loop_candidate(self, frame1, frame2) -> bool:
    raise NotImplementedError(
        f"{type(self).__name__} must implement _verify_loop_candidate. "
        "Loop closure cannot run without per-backend verification."
    )
```

**Add `MapAnythingCreator._verify_loop_candidate`:** DINO-cosine gate. Re-embed both frames using the existing DINO-SALAD model from `ImageRetrieval`; reject if cosine < `verify_match_ratio` (default 0.85, configurable per backend).

**Acceptance:** unit test confirms base class raises. MapAnything path now rejects synthetic dissimilar pair (cosine 0.3) and accepts synthetic similar pair (cosine 0.95).

### F7 — Pose convention assertion

**File:** `collab_splats/pointcloud/loop_closure/submap.py` + per-backend in `feedforward.py`.

**Change:** add `assert_world_to_cam(poses: np.ndarray) -> None` to `submap.py` checking `poses` shape + that `poses[0]` is approximately `eye(4)` for first frame of submap (VGGT/MapAnything return identity-at-frame-0). Fallback rule for backends violating this: docstring + explicit conversion in their `_run_inference`.

Call assertion in `_run_inference` after extracting `raw["extrinsic"]`. **Note:** verification confirmed VGGT outputs world-to-cam (matches our convention). Assertion guards against future regression and backend mismatch.

**Acceptance:** unit test passes synthetic identity-first pose array. Failing test (random pose at frame 0) raises with clear message.

### F8 — Threshold tuning + cosine semantics

**File:** `collab_splats/pointcloud/loop_closure/retrieval.py` (`LoopClosureConfig`).

**Change:**
- Add `lc_cosine_threshold: float = 0.85` (new field, human-readable cosine)
- Internally convert to L2: `lc_threshold_l2 = sqrt(2 * (1 - lc_cosine_threshold))`
- Deprecate raw `lc_threshold` field. Keep for backward compat with `DeprecationWarning` if explicitly set.
- Default behavior change: 0.95 L2 (cos≈0.549) → 0.85 cosine (L2≈0.548).

**Acceptance:** unit test confirms `cos=0.85 ↔ L2=0.5477`. Default config produces L2 threshold ≈ 0.548.

### F9 — NMS on loop candidates

**File:** `collab_splats/pointcloud/loop_closure/retrieval.py:LoopMatchQueue`.

**Change:** add `nms_frame_distance: int = 25` to `LoopClosureConfig`. In `LoopMatchQueue.push` (or a new `finalize()` method called once per submap), suppress candidates within `nms_frame_distance` of an already-accepted higher-scoring candidate. Implement as O(k²) Python loop — k is small (≤max_loops_per_submap), no need for numba.

**Acceptance:** unit test with 5 candidates at frames `[10, 12, 50, 53, 100]` and `nms=25` returns `[10, 50, 100]` (best-of-cluster wins).

### F10 — Raise max_loops_per_submap

**File:** `collab_splats/pointcloud/loop_closure/retrieval.py:LoopClosureConfig`.

**Change:** `max_loops_per_submap: int = 1` → `int = 5`. Single-line change.

**Acceptance:** integration test with multi-loop scene admits >1 loop per submap.
